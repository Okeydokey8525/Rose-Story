# Project Overview

**Project Name**: Rose Garden
**Genre**: 3D Cozy Gardening Game
**Language**: Python
**Core Framework**: Pygame

## Goals

The primary goal of Rose Garden is to build a cozy 3D game strictly using a custom software renderer built with Python and Pygame. The project strictly forbids relying on existing 3D game engines.

## Scope & Minimal Viable Product (MVP)

The MVP is highly focused on a simple, singular gameplay loop:
- The game revolves around planting and taking care of roses.
- The environment consists of a garden with a soil grid.
- The camera observes the garden from a fixed or limited perspective.
- The player interacts directly with the soil patches.
- There is no free-roaming character in the MVP.
- All visual elements will initially be simple procedural geometry or primitive meshes before considering any complex external assets.

The game is designed to be extensible in the future, but the current implementation must remain small and focused strictly on the MVP requirements.
